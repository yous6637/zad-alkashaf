# زاد الكشاف

منصة عربية (مع فرنسية) للأفواج الكشفية في الجزائر: تسجيل الفوج، اشتراك سنوي، أعضاء، نشر عتاد، بحث، تواصل، وبلاغات تراجعها الإدارة.

## التشغيل

```bash
npm install
npm run dev
```

المعاينة تفتح على `http://127.0.0.1:8080` وتستخدم PGLite. لا حاجة إلى ملف `.env` في المعاينة. أول زيارة تطبّق ملفات `migrations/*.sql` بما فيها `seed.sql` (58 ولاية، تصنيفات، باقة واحدة).

```bash
npm run typecheck
npm run lint
npm run build
```

## المتغيرات

| المتغير | متى |
|---|---|
| `DATABASE_URL` | عند النشر فقط. بدونه تُتخطى هجرة `pg` وتعمل PGLite. |
| `BETTER_AUTH_SECRET` | سر الجلسات في الإنتاج. المعاينة تولّد سراً محلياً. |
| `BETTER_AUTH_URL` | عنوان الموقع العام في الإنتاج. |

لا تضع حدود الباقة (السعر، الأيام، الأعضاء، المنتجات) في الكود. تُقرأ من جدول `plans`، وتُنسخ إلى الاشتراك عند الطلب.

## الهجرات

`npm run build` يشغّل `npm run db:migrate`. الملفات في `migrations/` تُطبَّق مرة واحدة وتُسجَّل في `_migrations`. الترتيب: `0001_auth.sql` ثم `0002_zad.sql` ثم `0003_spec.sql` ثم `seed.sql`.

مجلد `migrations/auth/` لا يُطبَّق وحده. النسخة المعتمدة هي `migrations/0001_auth.sql`.

## أول مسؤول

1. سجّل حساباً من `/ar/register`.
2. إذا لم يوجد مسؤول بعد، صفحة الحساب تعرض تفعيل الإدارة لأول حساب.
3. أو بعد معرفة معرّف المستخدم في جدول `"user"`:

```sql
update profiles set role = 'admin' where id = '<user id>';
```

## ما يفعله الاشتراك

- طلب الاشتراك ينسخ السعر وحد الأعضاء وحد المنتجات من الباقة النشطة.
- الإدارة توافق، فتُحسب نهاية المدة من `duration_days` في الباقة وقت الموافقة.
- تعديل الباقة لا يغيّر اشتراكاً قائماً. الطلب التالي يأخذ الحدود الجديدة.
- عند انتهاء `ends_at` تختفي المنتجات من البحث وصفحة الفوج. بيانات الفوج تبقى.

## النشر

اربط المستودع بخدمة تدعم Node واضبط `DATABASE_URL` على Postgres. أمر البناء `npm run build` ينفّذ الهجرة. الواجهة عربية من الجذر `/`، والفرنسية من `/fr`.

تفاصيل الجداول والسياسات في [docs/SCHEMA.md](docs/SCHEMA.md).
